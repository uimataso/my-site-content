# 我的大腦是有極限的

這一兩個月的工作負荷有點太大了：白天工作有兩個專案、跟同事私下接了兩個案子、還有自己想做的 Side Projects（日檢 N2、自組 NAS 等等）。

以時間的規劃來上說，是可以做的下去。但是我覺得我的大腦的頻寬不夠。

在白天工作中，我已經把 70%~90% Coding 任務交給 Agent。雖然生產力是上升了，但我也被迫“多工”。

有用過 Agent 打程式的人應該能夠體會，在把 prompt 送出去後，到有成果出來前，工程師（我）除了等，是沒事幹的。自然而然，在這段時間裡面我就去研究下一個功能、開發其他專案、處理一些雜事，等到 Agent 告一段落後，又回來準備下一個 Prompt。

不斷內容切換的開銷，與維持內容在大腦內所需的成本，讓我覺得我比之前更容易累了。明明“實際上”做的事情比之前少。

覺得累 -> 感到 Burn out -> 不想工作

不想工作在耍廢的時候，我的內心又一直跟我說我現在應該要做一些正事了，讓我耍廢的時候還有罪惡感，不夠廢！

我一直覺得“第二大腦”是有機會幫助我降低大腦負擔的一個方式。我從幾年前就有這種想法了。但是（每個事情都有但是），我一直很不滿意現有的工具。

目前感覺最好的是 Emacs 的 Org mode，但我是一個 Neovim guys，雖然我並不排斥用 Emacs 本身，但就算使用 Evil mode 跟寫很多 Lisp，它終究跟我平常用的編輯器不一樣。

Neovim 自己當然有很多筆記插件，但是以 Markdown 為基礎的插件的少了 Agenda 相關的功能；以 Org 或其他格式為基礎的又跟這個世界不合。

但就算我有完美的工具，我真的就會用嗎？

我知道很多事情可以提升我的生活品質或效率，像是 Multi cursor、Debugger、Quickfix list 等，但是我就是無法將它們融入我的肌肉記憶裡。只要我還可以用舊的方式來做，新的事情就是很難融入我的生活裡。

第二大腦系統當然也算在這個類別裡。怎麼要才能記得把事情加到清單內，怎麼樣才能記得清理完成的項目，怎麼樣才能把這個事情變成我的肌肉記憶？

其實我有一個新的行為成功融入生活的案例：我已經成功持續記帳 10個月了。每次有付錢的動作的時候，不管是現金、刷捷運、掃支付，我就會馬上把帳記下。

說不定關鍵是要有 Trigger。

我不是不想做新的嘗試，我只是在要做的時候不記得要做而已。只是我的大腦還沒有把新的行為連結到日常的事情而已。

付錢到記帳、衣服沒了到洗衣服、肚子餓到吃飯，也許我只要幫我的代辦清單找一個 Trigger。

沒想到只是想分享一下我最近好忙，還可以寫出一些新想法，真好。
